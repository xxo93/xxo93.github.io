链表的中间结点

给定非空单链表头节点 head，返回中间结点。如果有两个中间结点，返回第二个。 经典解法：快慢指针——slow 每次走 1 步，fast 每次走 2 步，fast 到末尾时 slow 正好在中点。

slow = slow.next　｜　fast = fast.next.next　（fast 到末尾时停）
fast 速度是 slow 的 2 倍，fast 走完全程时 slow 正好走了一半。
示例用例：

操作日志

一、为什么快慢指针能找到中点？

直觉：两个人在直跑道上跑，快的速度是慢的 2 倍。当快的人到达终点时，慢的人正好跑了一半——这就是中点。
链表没有数组下标，只能顺着 next 走，所以用快慢指针模拟这个过程。

为什么偶数个节点时 slow 停在"第二个"中间节点？ 因为 while 条件是 fast && fast.next。当链表有偶数个节点时，fast 会在"再走两步就 null"的那一步停住，此时 slow 恰好走到第二个中间节点。这正好符合题目要求。

三、带注释的 Python 代码

class Solution: def middleNode(self, head: ListNode) -> ListNode: # 快慢指针同时从 head 出发 slow = fast = head # fast 要走两步，所以必须保证 fast 和 fast.next 都存在 while fast and fast.next: slow = slow.next # 乌龟走 1 步 fast = fast.next.next # 兔子走 2 步 # fast 到末尾时，slow 正好在中点 # 偶数个节点时 slow 停在第二个中间节点（题目要求） return slow

四、朴素解法 vs 快慢指针

方案做法时间空间遍历次数
朴素先数长度 n，再走 n/2 步O(n)O(1)2 趟
快慢指针slow 1 步、fast 2 步同步走O(n)O(1)1 趟

两者复杂度相同，但快慢指针只遍历一趟，代码更优雅，也是面试标准答案。

五、复杂度

时间 O(n)：fast 走完全程约 n/2 轮，每轮 slow 走 1 步，共 O(n)。
空间 O(1)：只用两个指针。
