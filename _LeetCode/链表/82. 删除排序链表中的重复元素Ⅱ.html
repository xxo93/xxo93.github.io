删除排序链表中的重复元素 II

给定已排序链表头节点 head，删除所有重复数字的节点（只要出现重复就全部删掉，一个都不留），只留下不同的数字。 返回已排序的链表。经典做法：哨兵节点 + 双指针。

检查 cur.next.val 是否等于 cur.next.next.val；若相等，while 循环把所有值相等的节点全删掉；否则 cur 前进一步
注意：83 题是"去重保留一个"，本题是"重复的全部删除"，所以要用哨兵节点处理头节点可能被删的情况。

操作日志

一、思路：为什么需要哨兵节点？

本题和 83 题最大的区别：83 题是"重复的保留一个"，头节点永远不会被删；本题是"重复的全部删掉"，头节点可能就是重复的（比如 [1,1,1,2,3] 要变成 [2,3]）。 所以必须在头节点前面加一个虚拟哨兵 dummy，让 cur 从 dummy 出发，统一处理所有情况。

核心逻辑：cur 永远指向"已经确定保留的最后一个节点"。它的下一个节点是 cur.next，再下一个是 cur.next.next。

  1. 如果 cur.next.val == cur.next.next.val：说明从 cur.next 开始有一段连续重复值，进入内层 while 循环，把所有值相等的节点全删（cur.next = cur.next.next）。
  2. 否则：cur.next 是孤值，保留它，cur = cur.next 前进一步。
  3. 直到 cur.next 或 cur.next.next 为空，结束。

三、带详细注释的 Python 代码

class Solution: def deleteDuplicates(self, head): # 哨兵节点：dummy.next 指向原链表头，处理头节点被删的情况 cur = dummy = ListNode(next=head) # 只要后面还有两个节点就继续检查 while cur.next and cur.next.next: val = cur.next.val # 后两个节点值相同 → 发现重复 if cur.next.next.val == val: # 把所有值等于 val 的节点全部删掉 while cur.next and cur.next.val == val: cur.next = cur.next.next # 跳过当前节点 else: # 不重复，cur 前进一步，保留这个节点 cur = cur.next return dummy.next

四、常见追问

  • 为什么内层 while 结束后 cur 不用前进？因为内层 while 删掉的是"一段连续重复值"，删完后 cur.next 指向的是下一个不同值的节点，cur 本身还停在"上一个保留节点"，需要重新检查新的 cur.next 和 cur.next.next 是否重复。
  • 为什么不用快慢指针？因为链表已排序，重复值一定连续，所以只需要检查 cur.next 和 cur.next.next 两个节点即可。
  • 83 题和 82 题区别？83 题"去重保留一个"，cur = cur.next 就行；82 题"重复全删"，需要内层 while 删一段。

五、复杂度

时间 O(n)：每个节点最多被访问两次（外层 while 一次，内层 while 删除时一次）。
空间 O(1)：只改指针，不新建节点。
