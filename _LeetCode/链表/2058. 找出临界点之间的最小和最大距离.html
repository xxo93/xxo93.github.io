操作日志

一、题目本质

这道题其实是两步走：

  1. 找位置：遍历链表，把所有临界点的下标收集到一个数组 s_list 里。
  2. 算距离：在 s_list 这个递增数组上，求「相邻元素差值的最小值」和「首尾元素差值」。

链表本身不需要反转、不需要额外结构，只需要一次快慢式遍历（实际是 pre 和 cur 两个指针同步前移）。

二、为什么「首尾差」就是最大距离？

关键观察：临界点下标是严格递增的。假设临界点下标为 [c₁, c₂, ..., cₖ]， 那么任意两个临界点 cᵢ, cⱼ (i<j) 的距离是 cⱼ − cᵢ。 要让这个值最大，显然要让 cⱼ 尽可能大、cᵢ 尽可能小 —— 也就是 cₖ − c₁。 所以最大距离 = 最后一个临界点 − 第一个临界点，不需要枚举所有配对。

三、为什么「相邻差的最小值」就是最小距离？

关键观察：对递增数组 [c₁, c₂, ..., cₖ]，任意不相邻两点 cⱼ − cᵢ (j>i+1) 一定 大于等于它们之间某一段相邻差（因为 cⱼ − cᵢ = (cᵢ₊₁−cᵢ) + (cᵢ₊₂−cᵢ₊₁) + ... + (cⱼ−cⱼ₋₁)， 每段都是正数）。因此最小距离一定出现在两个相邻临界点之间，只需遍历 s_list[p+1] − s_list[p] 取最小即可。

四、判定逻辑真值表

对于中间节点 cur（即有 pre 和 next），四种情况：

cur 与 precur 与 next是否临界点类型
cur > precur > next是▲ 极大
cur < precur < next是▼ 极小
cur > precur < next否上升沿
cur < precur > next否下降沿
任意相等—否要求严格不等

注意：题目要求严格大于/严格小于，相等不算。这就是为什么示例 4 [2,3,3,2] 没有临界点 —— 中间两个 3 相等。

五、边界条件

  • 节点数 < 3：连一个"同时有前驱和后继"的节点都没有，直接返回 [-1,-1]。
  • 临界点只有 1 个或 0 个：凑不出两个不同临界点，距离无意义，返回 [-1,-1]。
  • 首尾节点：不可能成为临界点，因为缺少一边的邻居。遍历时 cur 从第 2 个节点走到倒数第 2 个节点。

六、带详细注释的 Python 代码

class Solution: def nodesBetweenCriticalPoints(self, head: Optional[ListNode]) -> List[int]: # ---------- 1. 初始化结果 ---------- min_res = -1 # 任意两点最小距离；不足两点时保持 -1 max_res = -1 # 任意两点最大距离；不足两点时保持 -1 # ---------- 2. 边界：节点数 < 3，不可能有临界点 ---------- # head.next.next 为空意味着最多两个节点 if not head.next.next: return [min_res, max_res] # [-1, -1] # ---------- 3. 一次遍历收集临界点下标 ---------- # min_p 记录当前 cur 节点的 1-based 下标； # head=1, head.next=2, ... 所以初始为 2 min_p = 2 s_list = [] # 收集所有临界点的 1-based 下标 pre = head # 前驱指针 cur = head.next # 当前指针（从第二个节点开始检查） # 循环条件：cur 必须有后继，才能形成 (pre, cur, next) 三元组 while cur.next: # 判定临界点：严格大于两端 OR 严格小于两端 is_max = (cur.val > pre.val) and (cur.val > cur.next.val) is_min = (cur.val < pre.val) and (cur.val < cur.next.val) if is_max or is_min: s_list.append(min_p) # 记录临界点的 1-based 下标 # 指针前移：下标 +1，pre 走到 cur，cur 走到 cur.next min_p += 1 pre = cur cur = cur.next # ---------- 4. 临界点少于两个，返回 [-1, -1] ---------- if len(s_list) < 2: return [min_res, max_res] # ---------- 5. 计算最大距离 = 尾下标 - 首下标 ---------- # 先把 min_res 也初始化为这个值，再在相邻差里找更小的 p = 0 min_res = max_res = s_list[-1] - s_list[0] # ---------- 6. 遍历相邻差值，更新最小距离 ---------- # s_list[p+1] - s_list[p] 是每一段相邻临界点的距离 while p < len(s_list) - 1: min_res = min(min_res, s_list[p+1] - s_list[p]) p += 1 return [min_res, max_res]

七、复杂度分析

时间复杂度 O(n)：链表节点共 n 个，主循环每个节点访问一次，s_list 再扫描一次，均为线性。
空间复杂度 O(k)：k 是临界点个数，最坏情况（交替高低）k ≈ n/2。 若想把空间压到 O(1)，可以在遍历时只记录"第一个临界点 first"、"上一个临界点 last"和"当前最小距离 minD"， 不保存整个 s_list —— 但代码可读性会下降。

八、O(1) 空间的进阶写法（可选）

def nodesBetweenCriticalPoints(self, head): if not head.next.next: return [-1, -1] first = -1 # 第一个临界点下标 last = -1 # 上一个临界点下标 minD = 10**5 # 当前相邻最小距离，初始化为大数 idx = 2 pre, cur = head, head.next while cur.next: if (cur.val > pre.val and cur.val > cur.next.val) or \ (cur.val < pre.val and cur.val < cur.next.val): if first == -1: first = idx else: minD = min(minD, idx - last) # 和上一个临界点的差 last = idx idx += 1 pre, cur = cur, cur.next if first == last: return [-1, -1] return [minD, last - first]

这种写法边遍历边算，不需要 s_list，空间 O(1)。但本题 n 上限 10⁵，两种写法都能 AC，教学上用 s_list 更直观。
