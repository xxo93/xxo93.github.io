反转链表 II

给定链表头节点 head 和整数 left、right（left ≤ right），反转从位置 left 到 right 的节点，返回反转后的链表。 用哨兵节点 + 三指针反转中间段 + 接回。

p0 走到 left 前一个 → 三指针反转 n=right-left+1 个节点 → p0.next.next=cur, p0.next=pre
为什么用哨兵？因为 left=1 时头节点可能被换，p0 从 dummy 出发不用特殊处理。

操作日志

一、思路：三段式

为什么要三段？反转中间段时，我们需要知道"段的头在哪、段的尾在哪、段后面接谁"。 所以：① 先用 p0 找到 left 前一个节点；② 在中间段做三指针反转；③ 把反转后的段接回 p0 和后面的链表。
  1. 找 p0：从 dummy 出发，走 left-1 步，停在 left 的前一个节点。
  2. 反转中间段：pre=null, cur=p0.next，用标准三指针反转 n=right-left+1 个节点。
  3. 接回：p0.next.next = cur（段尾接上后面的链表），p0.next = pre（p0 接上反转后的新头）。

三、带详细注释的 Python 代码

class Solution: def reverseBetween(self, head, left, right): # 哨兵节点：处理 left=1 时头节点被换的情况 dummy = ListNode(next=head) # ① 找 p0：left 的前一个节点 p0 = dummy for _ in range(left - 1): p0 = p0.next # ② 反转中间段（标准三指针，n=right-left+1 个） pre = None cur = p0.next # cur 从 left 开始 for _ in range(right - left + 1): nxt = cur.next cur.next = pre # 反转指向 pre = cur # pre 前移 cur = nxt # cur 前移 # ③ 接回：段尾（原 left 节点）接上 cur，p0 接上新头 pre p0.next.next = cur # 原来的 left 节点现在是段尾，接后面的链表 p0.next = pre # p0 接上反转后的新头 return dummy.next

四、常见追问

  • 为什么 p0.next.next = cur？因为反转完后，p0.next 还是原来的 left 节点（现在它是段尾了），它的 next 指向 null（因为 pre 初始为 null）。所以要把它接上 cur（cur 已经是 right 后面的节点）。
  • 为什么用 dummy 而不是直接处理 head？如果 left=1，反转后的新头不是原 head，直接用 head 会丢失头节点引用。dummy 让 p0 从 dummy 出发，p0.next 始终指向新头。
  • 为什么最后一步顺序不能反？必须先 p0.next.next = cur，再 p0.next = pre。因为如果先 p0.next = pre，p0.next 就变成 pre 了，原来的 left 节点引用就丢了，p0.next.next 就接错了。

五、复杂度

时间 O(n)：最多遍历一次。
空间 O(1)：只用常数个指针。
