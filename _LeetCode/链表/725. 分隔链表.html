分隔链表

给定链表头节点 head 和整数 k，把链表分成 k 个连续部分。 每部分长度尽量相等（差不超过 1，前面的更长），前面部分 ≥ 后面部分。返回长度为 k 的数组。

n = 链表长度　avg = n // k　前 n % k 段长度 = avg+1，其余 = avg
先数总长，再按"整除 + 余数分配"切分，最后一段尾节点指空。

操作日志

一、思路：先数长度，再按"整除+余数"分配

核心公式：n 个节点分 k 段，平均每段 n/k 个。如果 n 不能整除 k，余数 r 意味着前 r 段要多 1 个节点（题目要求"前面的更长"）。
即：avg = n // k，前 r 段长度 = avg + 1，其余段 = avg。

切分过程：用指针 curr 从 head 出发，对每一段：

  1. 记录 parts[i] = curr（本段头节点）；
  2. 沿着 curr 走 part_size - 1 步，到达本段尾节点；
  3. 保存 next_head = curr.next；
  4. 把 curr.next 置空（剪断尾节点，否则会串到下一段）；
  5. curr = next_head，进入下一段。

三、带详细注释的 Python 代码

class Solution: def splitListToParts(self, head, k): # 第 1 步：数链表长度 n n = 0 node = head while node: n += 1 node = node.next avg = n // k # 每段至少 avg 个 r = n % k # 前 r 段多 1 个 parts = [None] * k curr = head for i in range(k): parts[i] = curr # 本段长度：前 r 段多 1 size = avg + (1 if i < r else 0) # 走到本段尾节点（size-1 步） for _ in range(size - 1): if curr: curr = curr.next # 剪断尾节点，否则会串到下一段 if curr: next_head = curr.next curr.next = None curr = next_head return parts

四、常见追问

  • 为什么必须 curr.next = None？链表是按引用连接的，不剪断尾节点的话，parts[0] 会一路串到 parts[1]、parts[2]……返回的前几段会变成完整链表。
  • 为什么 k > n 时返回空段？n=3, k=5 时 avg=0, r=3，前 3 段各 1 个节点，后 2 段 size=0，parts[i] = curr（此时 curr 已为 null），自然就是 null。
  • 为什么要先遍历一次数长度？因为不知道每段该切多长，必须先知道总 n。两趟遍历：一趟数长度，一趟切分。

五、复杂度

时间 O(n)：数长度一趟 + 切分一趟，每个节点访问常数次。
空间 O(k)：返回长度为 k 的数组（不算输出空间则 O(1)）。
