合并两个有序链表

给定两个升序链表 list1 和 list2，将它们合并成一个新的升序链表并返回。 新链表通过拼接给定的两个链表的所有节点组成。经典做法：双指针 + 哨兵节点。

每次比较 p1.val 和 p2.val，较小者接到结果末尾，对应指针前移；一方走完后直接接上剩余部分
类似归并排序的 merge 步骤，两个指针各扫一遍，O(n+m)。

操作日志

一、思路：双指针 + 哨兵节点

为什么需要哨兵节点？如果不设哨兵，结果链表的第一个节点需要单独判断"是 p1 还是 p2"，代码会很啰嗦。 用一个虚拟头节点 pre_head，所有节点统一往它后面接，最后返回 pre_head.next 即可。

两个指针 p1、p2 分别从两个链表头出发：

  1. 比较 p1.val 和 p2.val，把较小者接到结果链表末尾；
  2. 被选中的指针前进一步；
  3. 重复直到某个指针走完（为 null）；
  4. 把另一个链表的剩余部分直接接到结果末尾（它们本来就是有序的）。

二、手动推导 [1,2,4] + [1,3,4]

三、带详细注释的 Python 代码

class Solution: def mergeTwoLists(self, list1, list2): # p1/p2 分别指向两个链表当前待比较节点 p1, p2 = list1, list2 # 哨兵节点：简化头节点处理，所有结果都往它后面接 pre_head = ListNode(-1) tail = pre_head # tail 永远指向结果链表的尾节点 # 双方都还有节点时，选较小者 while p1 and p2: if p1.val <= p2.val: tail.next = p1 # 把 p1 接到结果后面 p1 = p1.next # p1 前移 else: tail.next = p2 p2 = p2.next tail = tail.next # 结果尾指针前移 # 一方走完，另一方剩余部分直接接上（本身有序） tail.next = p1 if p1 is not None else p2 return pre_head.next

四、常见追问

  • 为什么最后直接接 tail.next = p1 or p2，不循环？因为剩下的部分本身就是有序的，且已经是链表结构，不需要再逐节点拷贝，直接用指针连起来就行——这是 O(1) 额外空间的关键。
  • 为什么比较用 ≤ 而不是 <？相等时选 p1 还是 p2 都可以，用 ≤ 保持稳定（相等时优先 list1），题目不要求稳定，但写 ≤ 更直观。
  • 递归写法行不行？可以：if not l1: return l2; if not l2: return l1; if l1.val<=l2.val: l1.next=self.mergeTwoLists(l1.next,l2); return l1。但递归深度是 O(n+m)，链表很长时会栈溢出，迭代更安全。

五、复杂度

时间 O(n+m)：每个节点被访问一次。
空间 O(1)：只改指针指向，不新建节点（结果链表复用原节点）。
