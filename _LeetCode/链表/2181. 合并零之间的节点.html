合并零之间的节点

给定一个链表 head，首尾都是 0，中间由若干个 0 分隔出多段整数。 把每两个相邻 0 之间的所有节点合并成一个节点（值为这段所有节点之和），然后删掉所有 0，返回新链表。

cur 遍历，cnt 累加；遇到 0 → 把 cnt 打包成新节点，cnt 清零
本质是一次扫描的"分段求和"：0 是段分隔符，非 0 是段内累加值。

操作日志

一、题目本质

链表首尾都是 0，中间被 0 切成若干段。要做的事：

  1. 把每一段内的所有非 0 节点值求和；
  2. 把这个和作为一个新节点，串成结果链表；
  3. 丢弃原始所有节点（包括分隔符 0）。

本质上是一次扫描的分段求和，和"用 0 作分隔符 split 字符串再求和"是同一个思路。

三、为什么遇到 0 时 cnt 不会把 0 也算进去？

关键：代码里 cnt += cur.val 在 if 判断之后。 遇到段尾 0 时，先用"旧 cnt"（也就是这一段非 0 节点的和）打包新节点，然后 cnt=0，再把当前 0 加进去（等于加 0，无影响）。
首节点 0 也是同理：cnt 初始就是 0，if 判断时 cnt!=0 不成立，不会误打包一个值为 0 的空节点。

四、带详细注释的 Python 代码

class Solution: def mergeNodes(self, head: ListNode | None) -> ListNode | None: # 哑节点，简化结果链表头的处理 pre_head = ListNode() p_head = pre_head # p_head 永远指向结果链表的尾节点 cur = head # cur 遍历原始链表 cnt = 0 # 当前段的累加和 while cur: # 遇到 0 = 一段结束（首节点 0 除外，那时 cnt 还是 0） if cur.val == 0: # cnt != 0 说明刚结束一段非 0 区间，打包成新节点 if cnt != 0: new_node = ListNode(cnt) p_head.next = new_node p_head = p_head.next # 尾指针后移 cnt = 0 # 无论是否打包，都清零，准备下一段 # 把当前节点值累加到 cnt（遇到 0 时加 0，不影响结果） cnt += cur.val cur = cur.next return pre_head.next

五、空间复杂度的小优化：原地修改

上面的写法新建了所有结果节点。实际上题目保证原链表不再被使用，可以直接在原链表上"原地压缩"：

def mergeNodes(self, head): cur = head.next # 跳过首 0 dummy = ListNode() tail = dummy while cur: s = 0 while cur.val != 0: # 内层循环累加一段 s += cur.val cur = cur.next tail.next = ListNode(s) # 或直接复用 cur 所在节点改值 tail = tail.next cur = cur.next # 跳过段尾 0 return dummy.next

两种写法时间都是 O(n)；新建节点空间 O(k)（k 为段数），原地修改可做到 O(1) 额外空间。

六、复杂度分析

时间复杂度 O(n)：每个节点被 cur 访问一次。
空间复杂度 O(k)：k 是合并后节点数（即段数），用于存结果链表本身；若不算结果空间，辅助变量只有 cnt / cur / p_head，O(1)。
