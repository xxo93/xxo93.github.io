环形链表

给定一个链表头节点 head，判断链表中是否有环。 若有环返回 true，否则返回 false。 经典解法：Floyd 快慢指针——乌龟每次走 1 步，兔子每次走 2 步。

slow = slow.next　｜　fast = fast.next.next
若有环，兔子一定会套圈追上乌龟；若无环，兔子先走到 null。

操作日志

一、为什么快慢指针能判圈？

直觉类比：两个人在环形跑道上跑步，快的人一定会在某一圈从后面追上慢的人（套圈）。 如果跑道是直的（无环），快的人先跑到终点（null），两人永远不会相遇。

数学证明：假设链表无环，fast 每轮走 2 步，必然先到达 null，循环退出。 若有环，设环长度为 L，进入环后 fast 相对于 slow 的速度是每轮 1 步（2−1）。 初始进入环时两人有距离差 d，最多 L 轮后 fast 一定追上 slow。

三、带注释的 Python 代码

class Solution: def hasCycle(self, head: Optional[ListNode]) -> bool: # 乌龟和兔子同时从起点出发 slow = fast = head # fast 要走两步，所以必须保证 fast 和 fast.next 都存在 while fast and fast.next: slow = slow.next # 乌龟走 1 步 fast = fast.next.next # 兔子走 2 步 # 兔子追上乌龟（套圈），说明有环 if fast is slow: return True # fast 走到链表末尾（null），无环 return False

四、常见追问

  • 为什么初始 slow=fast=head 时不立刻判等？因为还没移动，当然相等。代码是先移动再判等，正确。
  • fast 能不能走 3 步？可以，但走 2 步是最经典、最快相遇的选择。走 3 步时若环长为 2，fast 会"跳过" slow 永远追不上——所以步长与环长要互质才稳妥，2 是最简单的选择。
  • 能不能用哈希集合？可以：遍历链表，把每个节点存到 set 里，若遇到已存在的节点则有环。时间 O(n)，但空间 O(n)。快慢指针空间 O(1)，更优。

五、复杂度分析

时间复杂度 O(n)：无环时 fast 先到末尾，走了 n/2 轮；有环时 slow 走不到一圈就被追上。
空间复杂度 O(1)：只用两个指针变量。

六、拓展：142 题「环形链表 II」

如果题目进一步要求"返回环的入口节点"，用快慢指针第一次相遇后，把其中一个指针放回 head，然后两个指针都每次走 1 步，再次相遇的点就是环入口。这是 Floyd 判圈算法的经典推论。
