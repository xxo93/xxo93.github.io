反转链表

给定单链表头节点 head，反转链表并返回新头节点。 经典三指针：pre（已反转段的尾）、cur（当前节点）、nxt（下一个待处理）。 每轮 4 步，顺序不能错：先存 nxt → 反转 cur.next → pre 前移 → cur 前移。

nxt = cur.next　→　cur.next = pre　→　pre = cur　→　cur = nxt
为什么必须先存 nxt？因为一旦 cur.next 指向 pre，原来的 next 就丢了，不先存就找不到下一个节点。

操作日志

一、为什么是三指针？为什么顺序不能错？

核心难点：链表是单链表，每个节点只知道 next。一旦把 cur.next 指向 pre，就丢失了原来的 next 指针，找不到下一个节点了。
所以必须先 nxt = cur.next 把"下一个节点"备份下来，才能放心反转。

四个指针的职责：

  • pre：始终指向"已经反转好的那一段"的头节点（初始为 null）。
  • cur：当前正在处理的节点。
  • nxt：备份 cur 的下一个节点（防止断链）。

每轮 4 步的顺序为什么是这样？

  1. ① nxt = cur.next：先存下一个，因为下一步要改 cur.next，不存就丢了。
  2. ② cur.next = pre：反转当前节点的指向，让它指向已反转段。
  3. ③ pre = cur：pre 前移到 cur（现在 cur 成了已反转段的新头）。
  4. ④ cur = nxt：cur 前移到下一个待处理节点。

如果 ② 和 ③ 顺序反了，pre 还没指向 cur 就反转，就会错。如果 ① 放在 ② 后面，cur.next 已经改了，nxt 就存不到原来的下一个节点了。

三、带详细注释的 Python 代码

class Solution: def reverseList(self, head): # pre 指向已反转段的头，初始为 null pre = None # cur 指向当前正在处理的节点 cur = head while cur: # 只要 cur 不为空就继续 # ① 先备份下一个节点，否则反转后就找不到了 nxt = cur.next # ② 反转当前节点的指向：让它指向 pre（已反转段） cur.next = pre # ③ pre 前移到 cur（cur 成为已反转段的新头） pre = cur # ④ cur 前移到备份的下一个节点 cur = nxt # 循环结束时 cur = null，pre 就是新头 return pre

四、常见追问

  • 为什么最后返回 pre 而不是 cur？因为循环结束时 cur 已经走到 null（链表末尾之后），pre 才是最后一个被反转的节点，也就是新链表的头。
  • 递归怎么写？if not head or not head.next: return head; new_head = reverseList(head.next); head.next.next = head; head.next = None; return new_head。递归本质是从后往前反转，迭代是从前往后。
  • 为什么不能用两个指针？两个指针（pre, cur）反转 cur.next 后就丢失了原来的 next，必须用第三个指针 nxt 备份。

五、复杂度

时间 O(n)：每个节点处理一次。
空间 O(1)：只用三个指针，原地反转。
