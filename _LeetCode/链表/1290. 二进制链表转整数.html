二进制链表转整数

给你一个单链表 head，每个节点的值是 0 或 1， 表示一个二进制数，最高位在链表头部。返回它对应的十进制值。

ans = ans × 2 + head.val

操作日志

一、题目本质

这道题就是把一个按位存储在链表中的二进制数读出来。链表顺序和二进制书写顺序一致：最左边是最高位（MSB），最右边是最低位（LSB）。

例如 [1,0,1] 就是二进制 101，等于十进制 5。

二、核心公式：为什么是 ans = ans × 2 + bit？

类比：把十进制数 123 按位存成链表 [1,2,3]，怎么还原？
第 1 位读到 1：ans = 1
第 2 位读到 2：把已有结果左移一位（×10）再加新位 → 1×10+2 = 12
第 3 位读到 3：12×10+3 = 123
二进制完全同理，只是把 ×10 换成 ×2。

四、带注释的 Python 代码

class Solution: def getDecimalValue(self, head: ListNode | None) -> int: # ans 累积十进制值，从 0 开始 ans = 0 # 遍历链表，直到 None while head: # 核心公式：把当前 ans 左移一位（×2），再加上当前位的值 # 等价于位运算 ans = (ans << 1) | head.val ans = ans * 2 + head.val # 指针后移 head = head.next return ans

五、位运算写法（可选）

因为每一位都是 0 或 1，ans×2 + bit 等价于先把 ans 左移一位（腾出最低位），再用按位或写入新位：

while head: ans = (ans << 1) | head.val head = head.next

两种写法完全等价，×2 更直观，<<1 更贴近位运算语义。

六、复杂度分析

时间复杂度 O(n)：n 是链表长度，每个节点访问一次。
空间复杂度 O(1)：只用一个变量 ans，不额外开数组。

七、边界与注意点

  • 空链表：题目说链表不为空，但如果是 [0]，结果就是 0。
  • 前导零：例如 [0,0,1,1] 表示二进制 0011 = 3，算法自然处理，不需要特殊判断。
  • 最大长度 30 位：二进制 30 位约等于 10⁹，Python 的 int 没有溢出问题；C++/Java 用 int（32 位）刚好够，用 long long 更保险。
