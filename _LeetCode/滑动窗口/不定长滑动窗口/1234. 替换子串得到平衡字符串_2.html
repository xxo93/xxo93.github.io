算法解析

为什么用滑动窗口？

题意：替换一段连续子串，使 Q/W/E/R 各出现 n/4 次。等价于——找到一个最短窗口，窗口外面的每种字符数都不超过 n/4（因为窗口内的字符可以被替换成任意字符来补足缺少的）。

这正是一个「不定长滑动窗口」问题：窗口长度不固定，我们需要找到满足条件的最短窗口。

具体步骤

  • 统计所有字符的总出现次数，若已经平衡则返回 0。
  • 初始化窗口 [left, right]，left = 0。
  • 右指针 right 逐步右移，将 s[right] 的计数减 1（该字符进入窗口内）。
  • 当窗口外所有字符计数都 ≤ n/4 时，记录窗口长度，并尝试收缩左指针（left 右移，将 s[left] 计数加回）。
  • 遍历结束后，返回记录的最小窗口长度。

代码

from collections import Counter
from math import inf

class Solution:
    def balancedString(self, s: str) -> int:
        count_dict, m = Counter(s), len(s) // 4

        if all(count_dict[x] == m for x in "QWER"):
            return 0

        ans, left = inf, 0
        for right, c in enumerate(s):  # 枚举子串右端点
            count_dict[c] -= 1           # 窗口外该字符计数 -1
            while all(count_dict[x] <= m for x in "QWER"):
                ans = min(ans, right - left + 1)
                count_dict[s[left]] += 1  # 左端点字符计数加回
                left += 1                 # 收缩窗口
        return ans

复杂度

时间：O(n) — 左右指针各最多遍历字符串一次。

空间：O(1) — 只用了固定大小的计数器（4 个字符）。
