算法解析

为什么用排序 + 滑动窗口？

题意：移除最少元素，使剩余数组「最大值 ≤ 最小值 × k」。关键观察：保留哪些元素与它们在原数组中的顺序无关，只取决于它们的值。所以先排序。

排序后问题转化为：找一段最长连续子数组 [left, right]，使得 nums[right] ≤ nums[left] × k（右端是窗口内最大值，左端是最小值）。这就是标准的「不定长滑动窗口」。

最终答案 = 数组总长度 - 最长合法窗口长度。

具体步骤

  • 将 nums 从小到大排序。
  • 初始化 left = 0，遍历右指针 right 从 0 到 n-1。
  • 每步检查 nums[right] ≤ nums[left] × k：
    • 满足 → 记录窗口长度，更新最大值 wind。
    • 不满足 → left 右移，直到条件满足。
  • 最终答案 = n - wind。

代码

from typing import List

class Solution:
    def minRemoval(self, nums: List[int], k: int) -> int:
        nums.sort()                        # 排序，使问题转化为连续子数组
        wind = left = 0

        for right, c in enumerate(nums):  # 枚举右端点
            while c > nums[left] * k:      # 最大值 > 最小值 × k，收缩左边界
                left += 1
            wind = max(wind, right - left + 1)  # 更新最长合法窗口

        return len(nums) - wind              # 总数 - 最长窗口 = 最少移除数

复杂度

时间：O(n log n) — 排序 O(n log n) + 滑动窗口 O(n)，排序主导。

空间：O(1)（或 O(n)，取决于排序实现）。
