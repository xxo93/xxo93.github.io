算法解析

为什么用滑动窗口？

题意等价于：在数组中找一段最长的连续子数组，其中最多包含 2 种不同的元素。这正是「不定长滑动窗口」的经典模型——窗口大小不固定，我们需要在满足条件的约束下找到最长窗口。

具体步骤

  • 维护窗口 [left, right] 和一个哈希表 cnt 记录窗口内各水果类型的出现次数。
  • 右指针 right 逐步右移，将 fruits[right] 加入 cnt。
  • 当 len(cnt) > 2（超过 2 种水果）时，左指针右移收缩：移出元素计数 -1，计数归零则从 cnt 中删除。
  • 每步更新答案：ans = max(ans, right - left + 1)。

代码

from collections import defaultdict

class Solution:
    def totalFruit(self, fruits: list[int]) -> int:
        ans = left = 0
        cnt = defaultdict(int)     # 记录窗口内各类型出现次数

        for right, fruit_type in enumerate(fruits):
            cnt[fruit_type] += 1    # 右端元素进入窗口

            while len(cnt) > 2:    # 超过 2 种，收缩左边界
                out = fruits[left]
                cnt[out] -= 1
                if cnt[out] == 0:
                    del cnt[out]     # 计数归零，移出哈希表
                left += 1

            ans = max(ans, right - left + 1)
        return ans

复杂度

时间：O(n) — 左右指针各最多遍历一次。

空间：O(1) — 哈希表最多存 3 个键值对（常数级）。
