算法解析

题目到底在问什么？

把字符串想成一排连续摆放的字符卡片。你要在这排卡片里框出一段连续的区间， 要求区间里任何字符都只出现一次（不许撞车），问这个区间最长能有多长。

  • 子串 vs 子序列：子串必须连续。以 "pwwkew" 为例，答案是 "wke"（长度 3）， 而不是 "pwke"（长度 4）—— 后者跳着挑，属于子序列，不算。
  • 要的是长度：返回一个数字，不是那段字符串本身。
  • 空串也算：约束里 0 <= s.length，空串没有子串，答案是 0。

为什么可以用滑动窗口？

暴力做法是枚举所有子串再逐个查重，O(n²) 甚至 O(n³)。滑动窗口能成立，靠的是本题的两个性质：

  1. 窗口有单调性。一旦区间 [left, right] 里出现重复字符， 把 right 继续往右扩只会让重复更严重，绝不可能变好。 所以此时唯一有意义的动作是移动左指针缩小窗口，不必回头试别的右端点。 这正是「求最长」类不定长窗口的特征：窗口不合法就收缩左边界。
  2. 左指针永不回退。当 s[right] 和窗口内某字符撞车时， 只需把左端一路右移，移到「撞车的那个字符被甩出窗口」为止。 被甩出去的部分不可能再成为更优答案的起点，所以不用再回头看。

两个指针都只单向前进、各走最多 n 步，总时间就是 O(n)。

指针是怎么移动的？

指针什么时候动怎么动
right 右指针 每一轮都动，由 for 循环驱动 无条件 +1 向右扩张，尝试把 s[right] 纳入窗口
left 左指针 只在 s[right] 与窗口内字符撞车时才动 while 循环里反复 +1，把左端字符逐个甩出窗口， 直到 s[right] 不再重复为止；之后停住，不回退
ans 答案 每一轮末尾 用 right - left + 1 更新。必须先收缩到合法、再更新， 否则会把含重复字符的非法长度记进去

具体步骤

  1. 准备一个窗口集合 window（记录窗口内有哪些字符）、左指针 left = 0、答案 ans = 0。
  2. 右指针 right 从 0 到 n-1 依次遍历，取出 c = s[right]。
  3. 收缩：若 c 已在 window 中，循环执行 window.remove(s[left]) + left += 1，直到 c 不在窗口里。
  4. 扩张：把 c 加入 window，此时窗口保证无重复。
  5. 更新：ans = max(ans, right - left + 1)。
  6. 遍历结束返回 ans。空串时循环体一次都不执行，直接返回 0，无需特判。

代码（Python）

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        window = set()   # 窗口内出现过的字符
        left = 0         # 左指针：只增不减
        ans = 0

        for right, c in enumerate(s):        # 右指针：每轮无条件右移一格
            # 窗口不合法（c 已在窗口里）→ 收缩左边界直到恢复合法
            while c in window:
                window.remove(s[left])       # 移出左端字符
                left += 1                   # 左指针右移，缩小窗口

            window.add(c)                    # 扩张：纳入新字符
            ans = max(ans, right - left + 1)   # 合法后再更新答案

        return ans

另一种等价写法是用哈希表记录「字符 → 最近一次出现的下标」，撞车时把 left 一步跳到 max(left, 上次下标 + 1)，省掉内层 while。两者时间复杂度相同， 集合写法更直观，跳转写法常数更小。

复杂度

时间 O(n) right 走 n 步；left 虽然嵌在 while 里， 但它只增不减，整个过程最多也只走 n 步。两者相加仍是 O(n)，不是 O(n²)。
空间 O(min(n, m)) window 最多装下窗口内全部不重复字符，上限是字符串长度 n 与字符集大小 m 的较小值。 本题字符集有限（英文字母、数字、符号、空格），可视为常数级。
