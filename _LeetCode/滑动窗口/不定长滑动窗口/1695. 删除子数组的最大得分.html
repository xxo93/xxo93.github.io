算法解析

为什么用滑动窗口？

题目要求：删除一段元素互不相同的连续子数组，使得分（元素之和）最大。等价于：在数组中找一段最长（或和最大）的连续子数组，其中所有元素都不重复。

这是「不定长滑动窗口」的变体——窗口条件不是元素个数的上限，而是不允许重复元素。一旦发现右端新加入的元素在窗口内已存在，就必须收缩左边界直到重复消除。

核心变量

  • cnt：哈希表，记录窗口内每个元素的出现次数
  • window_sum（代码中 ans）：窗口内元素之和，随窗口伸缩实时更新
  • max_ans：历史最大窗口和，即最终答案

具体步骤

  • 初始化 left = 0，window_sum = 0，max_ans = 0，cnt 为空哈希表。
  • 右指针 right 从 0 遍历到 n-1：
    • 将 nums[right] 加入 cnt，window_sum += nums[right]。
    • 当 cnt[nums[right]] > 1（出现重复！），循环收缩：
      • window_sum -= nums[left]，cnt[nums[left]] -= 1，left += 1。
    • 更新 max_ans = max(max_ans, window_sum)。
  • 返回 max_ans。

代码

from collections import defaultdict

class Solution:
    def maximumUniqueSubarray(self, nums: List[int]) -> int:
        window_sum = left = 0
        cnt = defaultdict(int)        # 窗口内元素计数
        max_ans = 0

        for right, n in enumerate(nums):
            cnt[n] += 1                  # 右端元素进入窗口

            while cnt[n] > 1:           # 重复！收缩左边界
                cnt[nums[left]] -= 1
                window_sum -= nums[left]  # 和减去移出元素
                left += 1

            window_sum += n               # 和加上新元素
            max_ans = max(max_ans, window_sum)
        return max_ans

复杂度

时间：O(n) — 左右指针各最多遍历一次。

空间：O(n) — 哈希表最多存储 n 个不同元素。
