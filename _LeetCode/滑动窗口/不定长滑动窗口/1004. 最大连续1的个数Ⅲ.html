算法解析

题意转化

题目说"最多翻转 k 个 0"，意思是：在数组中选一段连续子数组，把其中的 0 全部翻成 1，翻转次数不超过 k。翻转后这段子数组就全是 1 了。

所以问题等价于：

找一段最长的连续子数组，其中 0 的个数 ≤ k。

窗口内的 0 就是我们要"翻转为 1"的那些位置，翻转次数 = 窗口内 0 的个数，不能超过 k。

为什么不能用暴力？

暴力做法：枚举所有子数组 [i, j]，对每个子数组数 0 的个数，看是否 ≤ k。时间复杂度 O(n²)，对于 n = 10&sup5; 会超时。

更聪明的做法：当我们把右端点从 j 扩展到 j+1 时，只需要多考虑一个新元素，不需要重新数整个子数组。这正是「滑动窗口」的核心思想——利用相邻子问题之间的重叠。

为什么用不定长滑动窗口？

「最多包含 K 个某元素的最长子数组」是不定长滑动窗口的经典模型。具体到本题：

  • 条件：窗口内 0 的个数 ≤ k（满足条件时窗口可以继续扩展）
  • 目标：找到满足条件的最长窗口
  • 收缩：当 0 的个数超过 k 时，左指针右移缩小窗口

窗口大小不固定，随着右指针扩展和左指针收缩动态变化，所以叫「不定长」。

核心变量追踪

维护一个计数器 cnt_0，记录当前窗口 [left, right] 内 0 的个数：

  • 右指针遇到 0：cnt_0 += 1（多了一个需要翻转的 0）
  • 左指针移出 0：cnt_0 -= 1（少了一个需要翻转的 0）
  • 每步更新答案：ans = max(ans, right - left + 1)

具体步骤

  • 初始化 left = 0，cnt_0 = 0，ans = 0。
  • 右指针 right 从 0 遍历到 n-1：
    • 如果 nums[right] == 0，则 cnt_0 += 1。
    • 当 cnt_0 > k 时，循环收缩左边界：
      • 如果 nums[left] == 0，则 cnt_0 -= 1。
      • left += 1。
    • 更新 ans = max(ans, right - left + 1)。
  • 返回 ans。

代码

class Solution:
    def longestOnes(self, nums: list[int], k: int) -> int:
        ans = left = 0       # ans: 最大窗口长度, left: 左边界
        cnt_0 = 0             # 窗口内 0 的个数

        for right, n in enumerate(nums):  # right: 右边界
            if n == 0:
                cnt_0 += 1                # 右端是 0，翻转次数 +1

            while cnt_0 > k:              # 翻转次数超标！收缩左边界
                if nums[left] == 0:
                    cnt_0 -= 1            # 左端是 0，翻转次数 -1
                left += 1                 # 左指针右移

            ans = max(ans, right - left + 1)  # 更新最长窗口

        return ans

复杂度

时间：O(n) — 右指针遍历一次，左指针最多也遍历一次，总共 O(n)。

空间：O(1) — 只用了 ans、left、cnt_0 三个变量。
