算法解析

为什么用滑动窗口？

题目要求删除恰好一个元素后，找全 1 的最长子数组。换个角度想：在原数组中找一段最多包含一个 0 的连续子数组，然后把那个 0 删掉就行了（全 1 时也必须删一个，所以窗口长 - 1）。

「最多包含 K 个某元素的最长子数组」是经典的不定长滑动窗口模型，这里 K = 1，目标是 0 的个数。

具体步骤

  • 维护窗口 [left, right] 和窗口内 0 的计数 cnt0。
  • 右指针 right 逐步右移，遇到 0 则 cnt0++。
  • 当 cnt0 > 1 时，左指针右移收缩，移出 0 则 cnt0--，直到 cnt0 ≤ 1。
  • 每步更新答案：ans = max(ans, 窗口长度 - 1)。减 1 是因为必须删一个元素。

代码

class Solution:
    def longestSubarray(self, nums: list[int]) -> int:
        res = left = 0
        cnt0 = 0  # 窗口内 0 的个数，最多允许 1 个

        for right, c in enumerate(nums):
            if c == 0:
                cnt0 += 1
            while cnt0 > 1:      # 超过 1 个 0，收缩左边界
                if nums[left] == 0:
                    cnt0 -= 1
                left += 1
            # 窗口长 - 1：删掉那个 0；全 1 时删一个 1
            res = max(res, right - left + 1 - 1)
        return res

复杂度

时间：O(n) — 左右指针各最多遍历一次。

空间：O(1) — 只用了几个变量。
