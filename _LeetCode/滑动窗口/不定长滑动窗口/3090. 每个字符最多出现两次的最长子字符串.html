算法解析

题目到底在问什么？

把字符串看成一排连续摆放的字符卡片。你要框出一段连续的区间（子串）， 要求区间里同一种字符最多只能出现 2 次——出现 1 次、2 次都合法，出现第 3 次就非法。 问这个区间最长能有多长，返回长度这个数字。

  • 「最多两次」是硬约束：以 "aaaa" 为例，任何长度为 3 的子串都含 3 个 a， 非法；最长只能取 "aa"，所以答案是 2，而不是 4。
  • 以 "bcbbbcba" 为例：开头的 "bcbb" 里 b 出现 3 次，非法； 末尾的 "bcba" 每个字符都只出现 1 次，合法且长度 4，这就是答案。
  • 要的是长度：返回数字，不是那段字符串本身。

和第 3 题是同一个模板

本题就是「无重复字符的最长子串」把上限从 1 改成 2。模板完全一样，只换判断条件：

对比项第 3 题本题 3090
窗口约束每个字符最多 1 次（不许重复）每个字符最多 2 次
非法判定c in windowcnt[c] > 2
窗口状态set（只记有没有）Counter（要记出现几次）
写法顺序先收缩、再把 c 加入集合先 cnt[c] += 1、再收缩
复杂度O(n) / O(min(n, m))O(n) / O(1)（仅 26 个小写字母）

把代码里的 2 换成任意常数 k，就变成通用题 「每个字符最多出现 k 次的最长子串」——本页面上方的「次数上限 k」输入框就是干这个的。

为什么可以用滑动窗口？

暴力做法是枚举所有子串再逐个统计次数：O(n²) 个子串、每个 O(n) 统计，共 O(n³)。 滑动窗口能做到 O(n)，靠的是两个性质：

  1. 窗口有单调性。一旦区间 [left, right] 里某个字符出现了 3 次， 把 right 继续往右扩只会让次数更多，绝不可能变合法。 所以此时唯一有意义的动作是移动左指针缩小窗口，不必回头试别的右端点。 这正是「求最长」类不定长窗口的特征：窗口不合法就收缩左边界。
  2. 左指针永不回退。收缩时把左端字符一个个甩出去，直到超标字符的次数降回 2。 被甩出去的那些位置，不可能再成为更优答案的起点，所以不用回头看。

两个指针都只单向前进、各走最多 n 步，总时间就是 O(n)。

一个关键简化：每轮只需要检查刚进来的那个字符 c 是否超标， 不必遍历全部 26 个字母。因为收缩前窗口是合法的（每个字符 ≤ 2）， 加入 c 之后唯一可能超标的就是 c 自己，其他字符的次数根本没变。 所以判断条件写成 while cnt[c] > 2 就够了。

指针是怎么移动的？

指针什么时候动怎么动
right 右指针 每一轮都动，由 for 循环驱动 无条件 +1 向右扩张；先执行 cnt[c] += 1 把新字符计入， 哪怕这会让窗口短暂非法
left 左指针 只在 cnt[c] > 2（刚进来的字符超标）时才动 while 里反复执行 cnt[s[left]] -= 1 + left += 1， 把左端字符逐个甩出，直到 cnt[c] 降回 2；之后停住，不回退
ans 答案 每一轮末尾 用 right - left + 1 更新。必须先收缩到合法、再更新， 否则会把含 3 个相同字符的非法长度记进去

具体步骤

  1. 准备计数表 cnt（字符 → 窗口内出现次数）、左指针 left = 0、答案 ans = 0。
  2. 右指针 right 从 0 到 n-1 依次遍历，取出 c = s[right]。
  3. 扩张：先 cnt[c] += 1，把 c 计入窗口。
  4. 收缩：若 cnt[c] > 2，循环执行 cnt[s[left]] -= 1 + left += 1，直到 cnt[c] ≤ 2。
  5. 更新：ans = max(ans, right - left + 1)。
  6. 遍历结束返回 ans。题目保证 n ≥ 2， 而任何长度 ≤ 2 的子串天然合法，所以答案至少是 2。

代码（Python）

from collections import Counter

class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        ans = left = 0
        cnt = Counter()                  # 窗口内每个字符的出现次数

        # 通过遍历方式扩展右边界
        for right, c in enumerate(s):
            cnt[c] += 1                 # 右边界移入（窗口可能短暂非法）

            # 收缩左边，直至满足条件：c 的次数降回 2
            while cnt[c] > 2:
                cnt[s[left]] -= 1        # 左边界移出
                left += 1               # 左指针右移，只增不减

            # 满足条件后再计算结果
            ans = max(ans, right - left + 1)

        return ans

把 while cnt[c] > 2 改成 while cnt[c] > k， 即可解决「每个字符最多出现 k 次」的通用版本，其余一字不改。

复杂度

时间 O(n) right 走 n 步；left 虽然嵌在 while 里， 但它只增不减，整个过程最多也只走 n 步。两者相加仍是 O(n)，不是 O(n²)。 每轮只检查刚进来的那一个字符，没有额外的 26 倍常数。
空间 O(1) cnt 最多存 26 个小写字母的计数，是固定上限，与 n 无关。 若字符集不限，则为 O(min(n, 字符集大小))。
