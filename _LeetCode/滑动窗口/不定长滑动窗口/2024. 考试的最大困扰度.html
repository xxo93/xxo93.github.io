算法解析

题意转化

给定 T/F 字符串，最多改 k 个字符，求最长连续相同字符子串。两种目标：

  • 全变成 T：需要把窗口内所有 F 翻成 T，翻转次数 = 窗口内 F 的个数 ≤ k
  • 全变成 F：需要把窗口内所有 T 翻成 F，翻转次数 = 窗口内 T 的个数 ≤ k
等价于：找最长子串，其中 T 的个数 ≤ k 或 F 的个数 ≤ k。
收缩条件：当 cnt['T'] > k 且 cnt['F'] > k 时（两种目标都不满足），左指针右移。

与 1004 题的对比

1004 题「最大连续1的个数 III」只翻转 0，窗口条件是 cnt_0 ≤ k。本题 T 和 F 都可以翻转，相当于对两种情况各跑一次滑动窗口取最大值，或者用合并条件 cnt['T'] > k and cnt['F'] > k 一次遍历。

核心变量

  • cnt['T'] / cnt['F']：窗口内 T/F 的计数
  • 收缩条件：cnt['T'] > k and cnt['F'] > k（两个都超标才收缩）
  • 每步更新：max_ans = max(max_ans, right - left + 1)

具体步骤

  • 初始化 left = 0，cnt = {}，max_ans = 0。
  • 右指针 right 从 0 遍历到 n-1：
    • 将 answerKey[right] 加入 cnt。
    • 当 cnt['T'] > k 且 cnt['F'] > k 时，左指针右移收缩。
    • 更新 max_ans = max(max_ans, right - left + 1)。
  • 返回 max_ans。

代码

from collections import defaultdict

class Solution:
    def maxConsecutiveAnswers(self, answerKey: str, k: int) -> int:
        max_ans = left = 0
        cnt = defaultdict(int)          # 窗口内 T/F 计数

        for right, c in enumerate(answerKey):
            cnt[c] += 1                 # 右端字符进入窗口

            while cnt['T'] > k and cnt['F'] > k:  # 两种都超标，收缩
                cnt[answerKey[left]] -= 1
                left += 1

            max_ans = max(max_ans, right - left + 1)
        return max_ans

复杂度

时间：O(n) — 左右指针各最多遍历一次。

空间：O(1) — 哈希表只存 T 和 F 两个键。
