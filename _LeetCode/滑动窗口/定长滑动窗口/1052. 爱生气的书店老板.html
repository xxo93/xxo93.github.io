算法解析

通俗理解题意

书店老板每天有 customers[i] 个顾客。如果当天老板生气 (grumpy[i] == 1)， 这些顾客就不满意；如果不生气 (grumpy[i] == 0)，顾客就满意。 老板有一个秘密技巧，可以让自已连续 X 分钟（天）不生气。 问：选择哪 X 天使用技巧，能让最多的顾客满意？

为什么用滑动窗口？

老板要选一段连续的 X 天使用技巧。在这 X 天里，原本生气的天的顾客都会变满意。 问题等价于：找一个长度为 X 的连续子数组，使得其中 grumpy[i]==1 对应的 customers[i] 之和最大。

暴力做法：枚举每个起点，重新求和，O(n·X)。但相邻两个窗口只差一个元素——右边移入一个、左边移出一个， 所以用滑动窗口 O(n) 搞定。

具体步骤

  • 第一步：先算"基础满意数"——老板本来就不生气的日子，顾客自然满意，把这些 customers[i] 加起来。
  • 第二步：在第一个窗口 [0, X-1] 里，只算 grumpy[i]==1 的那些天的 customers[i]（这些是用技巧能"救回来"的顾客）。
  • 第三步：窗口每次右移一格：左边移出的如果是生气天就减去，右边移入的如果是生气天就加上，更新最大额外满意数。
  • 第四步：遍历完，返回 基础满意数 + 最大额外满意数。

指针变化说明

左指针 L 指向窗口最左边的元素，右指针 R 指向窗口最右边的元素。 初始时 L=0, R=X-1。每次右移：L 向右移一格（移出窗口），R 也向右移一格（移入窗口）。

Python 代码

class Solution:
    def maxSatisfied(self, customers: List[int], grumpy: List[int], X: int) -> int:
        n = len(customers)
        base = 0

        # 第一步：算基础满意数（本来就不生气的日子）
        for i in range(n):
            if grumpy[i] == 0:
                base += customers[i]

        # 第二步：初始化第一个窗口的额外满意数
        extra = 0
        for i in range(X):
            if grumpy[i] == 1:
                extra += customers[i]
        max_extra = extra

        # 第三步：滑动窗口
        for i in range(X, n):
            if grumpy[i - X] == 1:   # 移出左端
                extra -= customers[i - X]
            if grumpy[i] == 1:       # 移入右端
                extra += customers[i]
            max_extra = max(max_extra, extra)

        # 第四步：返回结果
        return base + max_extra

复杂度分析

时间复杂度：O(n) — 每个元素最多被访问两次（初始化一次、滑动时各一次）。

空间复杂度：O(1) — 只用了几个整型变量。
